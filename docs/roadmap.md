# Roadmap (12-18 Months)

## Q1: 建立真实连接闭环

- 完成资料质量评分体系
- 推荐结果增加解释字段
- 上线连接推进状态机（推荐到初会）
- 打通行为事件采集

交付标准：
- MQC 环比持续增长
- 首次有效沟通率达到目标阈值

## Q2: 可解释推荐与实验体系

- 上线召回/重排策略版本管理
- 建立 A/B 实验流程
- 引入负反馈学习
- 形成周级策略评估报告

交付标准：
- 推荐接受率提升
- 策略回滚可在小时级执行

## Q3: 机构协作与组织化能力

- 上线机构团队视图和协作流
- 增加投研标签与项目对比能力
- 建立租户级看板

交付标准：
- 机构版续费率与活跃度稳定
- 团队协作效率可量化提升

## Q4-Q6: 平台化与区域扩展

- 推进多租户隔离治理
- 支持跨城市策略分区
- 优化成本结构与资源调度

交付标准：
- 单位有效连接成本下降
- 多区域质量指标稳定
