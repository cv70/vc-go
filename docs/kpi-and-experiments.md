# KPI & Experiment System

## 1. 指标体系

### 1.1 北极星指标
- `MQC`: 月度有效连接数

### 1.2 一级指标
- `Match Acceptance Rate`
- `First Effective Conversation Rate`
- `7-Day Progression Rate`
- `Founder M1 Retention`
- `Investor M1 Retention`

### 1.3 健康指标
- 推荐解释覆盖率
- 负反馈可解释率
- 噪声连接占比
- 审核通过率与申诉率

## 2. 漏斗定义

`推荐曝光 -> 查看 -> 发起联系 -> 获得回复 -> 初会 -> 深度尽调`

每层都要有：
- 转化率
- 中位耗时
- 损失原因 Top N

## 3. 实验框架

### 3.1 实验对象
- 召回策略
- 重排权重
- 解释文案形态
- 联系引导策略

### 3.2 实验约束
- 单次实验必须绑定单一主假设
- 指标窗口至少覆盖完整业务周期
- 严禁同时修改多核心变量导致归因失真

### 3.3 决策规则
- 达到收益阈值且无明显副作用：推广
- 收益不显著：继续观察或终止
- 伤害核心指标：立即回滚

## 4. 数据治理原则

- 统一事件命名与字段字典
- 指标定义版本化
- 报表口径单一真相源（Single Source of Truth）
