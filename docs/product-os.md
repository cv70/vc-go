# Product OS: 创业通的产品操作系统

## 1. 北极星与系统目标

### 北极星指标
- `MQC`（Monthly Qualified Connections）：月度有效连接数

### 三个一级目标
- 更准：提高推荐命中率与沟通质量
- 更快：缩短从发现到首次有效沟通的时间
- 更稳：在规模增长时保持质量与信任

## 2. 产品不是“功能集合”，而是“机制集合”

### 核心机制 M1：双边画像机制
- Founder 画像：阶段、赛道、融资目标、团队背景、证据材料
- Investor 画像：投资阶段、票面、偏好、禁投条件、历史风格
- 机制目标：把“模糊匹配”变为“结构化匹配”

### 核心机制 M2：可解释匹配机制
- 输出结果不止有分数，还要有“为什么匹配”
- 解释维度：阶段匹配、赛道匹配、票面匹配、地域/网络匹配、历史行为匹配
- 机制目标：让用户愿意基于推荐做动作

### 核心机制 M3：连接推进机制
- 把“匹配成功”定义为起点，而不是终点
- 线索阶段：推荐 -> 已查看 -> 已发起联系 -> 已回复 -> 初会 -> 深度尽调
- 机制目标：提高每一层转化率

### 核心机制 M4：反馈学习机制
- 正反馈：收藏、回复、约见、尽调推进
- 负反馈：阶段不符、赛道不符、质量不符、估值不符
- 机制目标：推荐系统每周可学习、每月可进化

## 3. 用户体验主线

### Founder 主线
1. 完善项目资料（最少必填 + 证据增强）
2. 获得 TopN 投资人推荐与解释
3. 选择联系策略（模板 + 个性化）
4. 查看推进状态和建议动作

### Investor 主线
1. 定义投资偏好与过滤条件
2. 获得候选项目池（低噪声）
3. 快速浏览关键事实与风险点
4. 一键反馈偏好，反哺下一轮推荐

## 4. 增长飞轮

`高质量资料 -> 更准匹配 -> 更高沟通率 -> 更多反馈数据 -> 更准匹配`

这个飞轮成立的关键不是流量，而是数据质量与机制完整度。

## 5. 商业化设计

### 收费对象
- Founder Pro：提升“融资连接效率”
- Investor Pro：提升“项目筛选效率”
- 机构版：团队协作、策略看板、投研流水

### 收费原则
- 每项收费能力都必须映射到“效率提升”或“命中率提升”
- 不卖“信息”，卖“确定性提升”

## 6. 护城河定义

- 数据护城河：高质量双边行为与反馈数据
- 机制护城河：可解释匹配 + 推进管理 + 反馈学习的组合
- 信任护城河：资料真实性、审计可追溯、低噪声社交环境
